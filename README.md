# Screener Bot

Telegram-бот на [aiogram 3](https://docs.aiogram.dev/), который оповещает о сильных изменениях цены на **Binance USDS-M Futures**.

Бот держит WebSocket-подписки на kline-стримы, сравнивает изменение свечи с порогом пользователя (`diff_percent`) и шлёт уведомление в Telegram.

## Возможности

- Подписка на алерты по проценту изменения цены за окно свечи (по умолчанию `15m`)
- Управление подписками через команды и inline-кнопки
- Фильтрация символов по 24h quote volume и возрасту листинга
- Админ-команды: обновление списка символов и статистика WS-движка
- SQLite + Alembic, опциональный proxy для Telegram Bot API

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (рекомендуется) или pip
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключи Binance API (для обновления списка символов через REST)

## Установка и запуск

1. Клонируйте репозиторий и перейдите в каталог проекта.

2. Установите зависимости:

```bash
uv sync
```

или через pip:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -e .
```

3. Создайте `.env` из примера и заполните переменные:

```bash
cp .env.example .env
```

Минимально нужны:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_LIST_ID` | ID админов через запятую |
| `BINANCE_API_KEY` / `BINANCE_API_SECRET` | Ключи Binance API |
| `LANGUAGE` | Локаль, например `ru` |
| `THROTTLING` | Задержка между запросами пользователя (сек) |

Опционально: `PROXY_URL` (`http://`, `socks4://`, `socks5://`), `DB_PATH`, фильтры символов и параметры WS-алертов — см. `.env.example`.

4. Примените миграции:

```bash
alembic upgrade head
```

5. Запустите бота:

```bash
python -m bot
```

или:

```bash
uv run python -m bot
```

После старта бот начинает polling и поднимает фоновый WebSocket-движок алертов.

## Команды

### Пользователь

| Команда | Описание |
|---|---|
| `/start` | Регистрация и приветствие |
| `/alert <percent>` | Включить/обновить подписку, пример: `/alert 4.0` |
| `/alert_off` | Выключить оповещения |

Также доступны настройки через кнопку «Настройки»: изменение порога и вкл/выкл подписки.

### Админ

| Команда | Описание |
|---|---|
| `/upd_symbols` | Обновить список фьючерсных символов (с фильтрами) и перезагрузить их в WS-движке |
| `/ws_stats` | Статистика WebSocket-движка алертов |

## Как это работает

1. Админ обновляет список символов (`/upd_symbols`) — в БД попадают пары, прошедшие фильтры объёма и истории.
2. Пользователь задаёт порог (`/alert` или UI).
3. Движок подписывается на kline-стримы Binance Futures и при закрытии свечи сравнивает `abs(change%)` с порогом.
4. При срабатывании отправляет сообщение пользователю (с dedupe, чтобы не дублировать один и тот же алерт).

## Структура

```
bot/
  __main__.py              # точка входа: polling + WS-движок
  handlers/                # user / admin команды
  keyboards/               # inline-клавиатуры
  middlewares/             # throttling
  db/                      # модели, config, сервисы
  screeners/               # Binance REST (символы) и WS-алерты
  migration/               # Alembic-миграции
```
